# Module Federation Example

This is a purely frontend Profile page which allows users the user to adjust settings and update data. The profile page settings are stored locally and is not connected to any backend. The settings reset to their default on page refresh.

This profile page contains the following sections.

- Profile - Allows user the change their name.
- Stats - Displays a visualization of user's saved data.
- Limits - Displays a visualization of a user's limits.
- Board Settings - Allows user to change settings.
- Tags - Allows user to edit their tag data.
- Deletion - Allows user to delete their profile.

## Technologies

This page is built with React, TypeScript, and Vite. Styling is done with Tailwind CSS along with shadcn components. Animations are implemented with Motion.
